# NUHA ANAM — Premium Portfolio Hero Section

Extraordinary, premium-quality animated hero section for **Nuha Anam** (Web Developer & AI Enthusiast), built with Next.js App Router, TypeScript, Tailwind CSS, Three.js, GSAP, and Lenis.

## ✨ Features

- **Personal Branding**: Features the `NA.` monogram, "HELLO, I'M NUHA ANAM", and "DESIGNING & DEVELOPING DIGITAL EXPERIENCES."
- **Apple & Lenis-Inspired Aesthetic**: Minimalist, futuristic dark mode (`#050505`), metallic tones, and signature pink neon accents (`#FF91A9`, `#FFB1C1`).
- **Interactive Three.js 3D Composition**:
  1. **Floating Dark Metallic Laptop**: Unibody chassis, chiclet keyboard, trackpad, and open display running a live syntax-highlighted IDE code editor with pink screen glow.
  2. **Floating Browser Window**: Glassmorphism chrome with traffic dots, URL pill, and modern web interface wireframe dashboard.
  3. **Abstract AI Object**: Pulsating faceted icosahedron core, counter-rotating wireframe cage, dual orbital rings, and an orbiting cloud of 60 glowing pink energy particles.
  4. **Smooth Mouse Parallax**: Fluid mouse tilt interpolation and sinusoidal idle floating.
- **Dynamic Particle System & Spotlight**: Canvas-based floating pink dust particles with ambient depth, low density on mobile, and a radial spotlight that softly follows the cursor.
- **GSAP & ScrollTrigger Animations**: Staggered text entrance, word-by-word reveal, and smooth button fades with `prefers-reduced-motion` safety.
- **Smart Custom Cursor**: Central dot + outer delayed follower ring, dynamically expanding to reveal contextual prompts like `"VIEW WORK →"` and `"LET'S TALK →"` on hover (disabled on touch devices).
- **Smooth Lenis Scrolling**: Kinetic buttery scrolling integration.
- **Responsive Architecture**: Fully optimized layout for mobile, tablet, laptop, and ultra-wide screens.

## 🚀 Getting Started

To run the development server locally:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore the live experience.

To create a production build:

```bash
npm run build
npm run start
```
